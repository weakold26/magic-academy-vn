# 하늘에 뜬 마법학원

> 마력을 감당하지 못하는 편입생과, 그를 감당하기로 한 두 사람.
> 브라우저에서 바로 플레이하는 판타지 비주얼 노벨.

**플레이:** https://weakold26.github.io/magic-academy-vn/

## 이 이야기

하늘에 떠 있는 여덟 개의 섬, 아이테르. 그중 가장 큰 섬의 왕립 마법학원에 한 편입생이
도착한다. 입학식의 마력 측정식에서 마석이 갈라지고, 대강당의 촛불이 한꺼번에 꺼진다.
그날 두 사람이 그의 손을 잡는다.

- **엘리제** — 성좌반 수석. 십 년째 자기 마력을 혼자 감당해 온 천재. 손을 잡으면 상대를
  태우는 체질이라, 아무도 곁에 두지 못했다. 도도하고 정확하고, 가끔 서툴게 다정하다.
- **세이아** — 치유학과 · 온실지기. 열두 살에 "성녀가 될 손"이라는 말을 듣고 자랐다.
  부드럽지만 위기에서 가장 강단 있는 사람. 자기 몫의 결정을 처음 고르는 이야기.

주인공은 제7형 공명체다. 마법을 쓰는 게 아니라, 마력에게 붙잡히는 몸. 학기말 심사를
통과하지 못하면 봉인되거나 학교에서 나가야 한다. 열두 주, 그리고 다섯 개의 결말.

## 엔딩

| NO | 구분 | 제목 |
|----|------|------|
| 01 | HAPPY END | 서리가 녹는 자리 |
| 02 | NORMAL END | 다음 별이 뜰 때 |
| 03 | HAPPY END | 온실의 봄 |
| 04 | NORMAL END | 약초와 편지 |
| 05 | TRUE END | 별빛을 함께 (히든) |

엔딩 도감은 `localStorage`에 저장되며, 타이틀 화면에서 확인할 수 있다.

## 기능

- 배경 4종 크로스페이드 (대강당 · 약초 온실 · 별빛 관측탑 · 달빛 호숫가)
- 스탠딩 2인 동시 연출 — 화자가 아닌 쪽은 자동으로 어두워진다
- 표정 4종 × 2인 (기본 / 수줍음 / 놀람 / 진지), 표정 전환 시 얼굴 크기·위치 정렬
- 호감도 게이지 2종, 선택지 14곳 · 39개 응답
- 세이브 3슬롯 + 자동 저장, 백로그, 자동 진행, 스킵, 글자 속도 조절
- 엔딩 도감 5종 (미해금 항목은 잠금 표시)
- WebAudio API로 합성한 BGM 5무드 + 효과음 (외부 음원 파일 없음)
- 데스크톱·모바일 반응형, 선택지 숫자키(1~9), 스페이스/엔터 진행

## 구조

```
index.html            화면 골격
css/style.css         무대·대화창·UI
js/engine.js          노드 진행, 분기, 호감도, 세이브, 엔딩
js/audio.js           WebAudio 합성 BGM·효과음
src/data/scenario.json  시나리오 (906 노드)
tools/                시나리오 DSL, 자산 빌드, 전수 시뮬레이터
```

### 시나리오 저작

`tools/`에서 장별 파이썬 모듈이 `S.line()`으로 노드를 쌓고, `sN_*.py` → `scenario_build.py`가
`src/data/scenario.json`을 만든다. 이어지는 노드는 자동으로 연결되고, 선택지·분기는 라벨로
연결된다.

```bash
cd tools
python3 scenario_build.py   # 시나리오 빌드
python3 simulate.py         # 전수 검사: 도달 불가 노드·끊긴 링크·막다른 길·엔딩 도달·문장 점검
python3 build_assets.py     # 스탠딩 누끼·정렬, 배경 리사이즈 → assets/img
```

`simulate.py`는 호감도·플래그를 포함한 상태 공간을 BFS로 전부 탐색한다. 현재 결과:
906 노드 전부 도달 가능, 5개 엔딩 전부 도달, 끊긴 링크·무한 루프·문장 경고 0건.
